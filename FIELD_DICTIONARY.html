LP Canonical Field Dictionary

Every LP-level field the platform recognises, traced from the canonical field-mapping dictionary through to the LP Extract columns that hold the historical record. Each field is attributed to the party that owns it — the Agent BB reports it, the Shadow BB computes it, or the LP profile carries it independently of any single facility.

Who owns a field

The single most important distinction in this dictionary. An Agent BB value is what the agent bank told us; a Shadow BB value is what UBS decided. Several concepts exist in both worlds — advance rate, concentration limit, borrowing base, excess concentration — and are stored as separate columns precisely so the spread between them can be measured. That spread is what the Shadow BB exists to produce.

Agent BB

Extracted verbatim from the agent bank's workbook. Never overwritten by a Shadow BB run.

Shadow BB

UBS's own category, rate, limit or computed result. Server-authoritative — the engine writes it.

LP profile

Bank-wide attributes of the investor. Held on lp_master, copied onto each facility record.

derived marks fields the agent calculated rather than reported. They are display and cross-check only: the Shadow BB never treats them as inputs, because doing so would import the agent's own concentration and eligibility assumptions into UBS's numbers.

Type conventions

Four rules govern every cell in this dictionary. They are the ones most often got wrong.

  • Percents and rates are fractions. NUMERIC(7,4), where 0.9100 means 91%. They are numeric on the wire too — the API emits the raw fraction and the UI multiplies by 100 at render. A value ingested as 0.91 displays as 91%, never 0.91%. Inbound "91%", 91 and 0.91 all normalise to the same stored 0.91.
  • Money is exact dollars. NUMERIC(20,2), no formatted sibling column. The engine computes off the numeric, and DTOs format on the way out — so an abbreviated "$4.2B" input returns as "$4,200,000,000" and is never re-abbreviated.
  • LP-size fields stay text. AUM, NAV and Pension Assets are VARCHAR(50) on both tables, kept exactly as the agent reported them, because they describe the investor rather than feeding a calculation.
  • Concentration limits are the exception to the fraction rule. One NUMERIC(20,2) column holds either a percent of total uncalled (7.5) or an absolute dollar cap (25000000), told apart by magnitude at a 100,000 threshold. They are not on the fraction scale — treating them as one silently voids every dollar-denominated limit.
