# pe-sub-docs

Architecture documentation and API specification for the PE Sub Borrowing Base Platform.

## Contents

| File | Description |
|---|---|
| `SOLUTION_DESIGN.md` | Living architecture document — repositories, tech stack, schema, API routes, design decisions |
| `openapi.yaml` | OpenAPI 3.0 specification for `pe-sub-api` (v0.8.0, incl. security schemes) |
| `openapi-extraction.yaml` | OpenAPI 3.0 specification for `pe-sub-extraction` (port 3002, v0.1.0) |
| `pe-sub-platform.postman_collection.json` | Postman v2.1 collection (both services, with `X-Auth-User`/`X-Auth-Roles` headers) — imports into Talend API Tester |
| `PE-Sub-Platform-Solution-Design-v2.docx` | **Current** formal Word deliverable — as-built consolidation (July 2026). Generated by `scripts/generate-solution-design-v2.mjs` — run `npm run build:docx:v2` |
| `PE-Sub-Platform-User-Guide.docx` | User Guide for business users (Analysts and Account/Transaction Managers). Generated by `scripts/generate-user-guide.mjs` — run `npm run build:guide` |
| `PE-Sub-Platform-Solution-Design.docx` | Superseded v1.0 Word deliverable (June 2026 target-architecture draft); kept for history. Generated by `scripts/generate-solution-design.mjs` — run `npm run build:docx` |
| `scripts/` | Generators for the `.docx` deliverables (use the `docx` npm package; run `npm install` first). `SOLUTION_DESIGN.md` remains the canonical living reference |
